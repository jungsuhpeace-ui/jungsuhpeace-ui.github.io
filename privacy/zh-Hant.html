Breakfree 隱私權政策

生效日期: 2026-11-26

簡要說明

Breakfree 不需要註冊，你寫下的內容和紀錄不會傳送給開發者。所有紀錄只儲存在這台裝置上。

我們收集的資訊

開發者不收集任何個人資訊。應用程式不使用廣告、分析工具、位置、聯絡人、相機或麥克風。

儲存在裝置上的內容

你寫下的事情、預想與實際分數、擊碎紀錄以及設定（語言、顏色主題、聲音、震動）只儲存在裝置的應用程式儲存空間中。開發者無法查看。在應用程式內刪除、清除應用程式資料或解除安裝時會一併刪除。

沉重話語提示

當寫下非常沉重的話時，會出現一則簡短提示。這項檢查只在裝置上進行，你寫的內容不會被傳送到任何地方。

提供應用程式檔案的伺服器

應用程式的畫面檔案由 GitHub Pages 提供。GitHub 基於安全目的會記錄訪客的 IP 位址。詳情請參閱 GitHub 隱私權聲明：https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement

兒童

Breakfree 不是為兒童設計的應用程式。

變更

本政策如有變更，將連同新的生效日期公布在此頁面。
