Breakfree 隐私政策

生效日期: {{EFFECTIVE_DATE}}

简要说明

Breakfree 无需注册，你写下的内容和记录不会发送给开发者。所有记录只保存在这台设备上。

我们收集的信息

开发者不收集任何个人信息。应用不使用广告、分析工具、位置、通讯录、相机或麦克风。

保存在设备上的内容

你写下的事情、预想与实际分数、粉碎记录以及设置（语言、颜色主题、声音、振动）只保存在设备的应用存储中。开发者无法查看。在应用内删除、清除应用数据或卸载应用时会一并删除。

沉重话语提示

当写下非常沉重的话时，会出现一条简短提示。这项检查只在设备上进行，你写的内容不会被发送到任何地方。

提供应用文件的服务器

应用的界面文件由 GitHub Pages 提供。GitHub 出于安全目的会记录访问者的 IP 地址。详情请参阅 GitHub 隐私声明：https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement

儿童

Breakfree 不是为儿童设计的应用。

变更

本政策如有变更，将连同新的生效日期发布在此页面。
